# Stop Reinventing the Scheduler 

Four years ago I built an async I/O scheduler on io_uring. It works — but it isn't std::execution. A talk at CppCon 2025 on adopting senders in Asio codebases made me curious about where P2300 stands relative to my own infrastructure work. This talk is what I found: the model, the ecosystem, the gaps — and an honest assessment of whether you should care yet.
